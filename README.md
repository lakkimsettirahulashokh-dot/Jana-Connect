# JanaConnect — Public Services, Made Simple

A responsive, browser-only citizen information prototype. It helps visitors explore common public-service categories and prepare a basic checklist before contacting an official department.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. No installation, API key, server, or database is required.

## Features
- Responsive landing page and service directory
- Searchable service cards
- Interactive preparation checklists in a dialog
- Sample scheme categories and citizen guidance
- Mobile navigation

## Important
JanaConnect is an independent educational prototype, not an official government website. It does not submit applications, verify eligibility, or provide live government data. Service names and checklists are general examples. Always verify current requirements, fees, deadlines, and application links with the relevant official government department.

## Project structure
- `index.html` — page structure
- `styles.css` — responsive visual design
- `app.js` — service directory and interactions
